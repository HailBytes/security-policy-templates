# ISO 27001:2022 Control Mappings

This file maps each policy template in this repository to the relevant controls in ISO/IEC 27001:2022 Annex A. Use this during gap analysis, audit preparation, or Statement of Applicability (SoA) drafting.

> **Note:** ISO 27001:2022 reorganized Annex A into 4 themes (Organizational, People, Physical, Technological) with 93 controls. References below use 2022 numbering. Common 2013 equivalents are noted in parentheses where the mapping diverges.
